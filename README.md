## ✦ Mission

I work across enterprise support, Microsoft cloud infrastructure, security, automation, and AI-assisted engineering.

The goal is simple: **make systems faster and easier to operate without increasing the security blast radius.** I like turning repetitive support work into reliable automation, building tools that make technical work easier to reason about, and designing workflows that fail safely instead of dramatically.

```text

SECURE     the boundaries
AUTOMATE   the repetitive work
```

## ✦ Engineering Doctrine

- **Least privilege** — give systems only the access they actually need.
- **Defense in depth** — assume individual controls can fail.
- **Sandbox risky execution** — isolate first, trust later.
- **Verify inputs and outputs** — automation should not remove judgment.
- **Prefer repeatable systems** — eliminate hero-mode troubleshooting when a process can do it better.
- **Keep humans in control** — automation should improve decisions, not hide them.
