## ✦ Security Doctrine

```text
LEAST PRIVILEGE        → Grant only the access required.
DEFENSE IN DEPTH       → Assume one control can fail.
SANDBOX BY DEFAULT     → Isolate risky execution.
VERIFY BEFORE TRUST    → Validate inputs, outputs, and identity.
AUTOMATE CAREFULLY     → Speed should never erase guardrails.
REDUCE BLAST RADIUS    → Security architecture should contain failure.
```
