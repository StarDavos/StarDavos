## What we're about

Star Davos is an independent software studio built around a simple idea: **software should take weight off people, not move it around**.

We turn fragmented workflows into focused tools. We want fewer repetitive steps, clearer evidence, safer defaults, and more room for human judgment. AI is useful when it creates leverage and makes its limits clear. Automation is useful when it keeps the operator in control.

The work spans Microsoft support tooling, developer utilities, creator intelligence, certification learning, decision automation, research systems, and experiments that challenge whether a problem really needs more software.

## The operating doctrine

> Make it useful. Make it understandable. Protect the human on the other side.

- **Show the work.** Separate evidence from assumptions, and observations from predictions.
- **Keep control.** Least privilege, explicit approval for consequential changes, and a way to recover.
- **Earn the automation.** Start narrow, test the failure paths, then expand authority only when justified.
- **Keep things operable.** A smaller, clear system beats an impressive demo nobody can maintain.
- **Build with care.** Curiosity, discipline, and the desire to leave things better than we found them.

## Where this goes

Our strongest starting point is usually a messy, expensive workflow: switching between too many tools, investigating with missing context, rewriting the same answer, or rechecking a decision the system could explain.

**Bring us the messy workflow.** We want to understand the real cost, find the smallest useful solution, and make it safer and easier to operate.
